# EasyPOS roadmap
P1 MVP: auth, menu+recipes, tables, orders, payments, shifts, printing (KOT/bill), offline sync, reports.
P2: inventory, Daily Bazar (purchase → stock + cost), auto-deduct from recipes, food cost %, voids/refunds.
P3: multi-branch, super-admin, subscriptions.
P4: Foodpanda/Pathao/Foodi integrations, MFS gateways, kitchen display.
KOT routing: item.station = kitchen → kitchen printer; bar → counter printer.
Check NBR/VAT (Mushak) invoice requirements before launch.
